# iCloudEMS-style Student Portal

This is a responsive, front-end project inspired by the provided student-portal screenshots. It is a local demo, not connected to an institution or a payment gateway.

## Run it

Open `index.html` in a modern browser. No installation, server, or API key is required.

## What works

- Email/password demo sign-in (any valid email and password of four or more characters).
- Responsive dashboard, side menu, bottom navigation, profile, attendance, timetable, fees, report-card selector, QR modal, and notifications.
- Editable personal data and profile sections.
- Edit every provided student field—identity, family, contact, university, address, and IDs—through **Profile → Edit profile**.
- A manual timetable planner: switch weeks/months, select any day, and add, edit, or delete classes with the floating **+** button.
- Add/remove records in every extra module, including optional image/video/audio/document upload (keep files below 3 MB).
- Demo payments create a saved local receipt, update the outstanding fee, and provide a downloadable PDF from **Fees → All Fees**.
- Report Card offers editable course/grade data and downloadable PDF grade cards for each semester.
- All edits are persisted in the browser's `localStorage`; they never leave the device.

To reset the demo, clear this site's browser storage.
